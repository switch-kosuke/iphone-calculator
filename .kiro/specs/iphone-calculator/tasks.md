# 実装計画

## タスク一覧

- [x] 1. プロジェクト基盤とHTMLマークアップの構築
- [x] 1.1 HTMLテンプレートとTailwind CDNのセットアップ
  - `index.html` を作成し、Tailwind CSS v3 Play CDN を `<script>` タグで導入する
  - `tailwind.config` をインラインで定義し、`ios-orange`（#FF9500）・`ios-dark`（#333333）・`ios-gray`（#a5a5a5）のカスタムカラーを登録する
  - 背景色 `bg-black`・画面中央配置・最大幅設定のレイアウト構造を定義する
  - GitHub Pages での公開を想定し、すべてのファイルをリポジトリルートに配置する構成にする
  - _Requirements: 1.1, 6.1_

- [x] 1.2 電卓の基本HTMLマークアップと静的ボタングリッドの作成
  - 計算結果を表示するエリアを画面上部に右寄せで配置する
  - ボタングリッドを `grid-cols-3` ベースで配置し、「1・2・3・+」「0・.・=」行を含む5行構成にする
  - 数字「0」ボタンを `col-span-2` の pill 形状（左寄せテキスト）で配置する
  - 各ボタンに `rounded-full`・`w-20 h-20`・`text-2xl` を基本スタイルとして適用し、色を種別ごとに分ける
  - 各ボタンに `aria-label` 属性を付与してスクリーンリーダー対応にする
  - _Requirements: 1.2, 1.3, 1.4, 1.5, 1.6, 6.3, 6.4_

- [x] 2. 演算エンジンの実装
- [x] 2.1 加算演算と表示フォーマット変換機能の実装
  - 2つの数値を足し算して返す計算関数を実装する（`toPrecision(12)` + `parseFloat` で浮動小数点誤差を丸める）
  - 整数の場合は小数点なし・小数の場合は末尾ゼロを省略して返すフォーマット関数を実装する
  - 結果が9桁を超える場合は指数表記（例: `1.23e+10`）に変換する
  - 入力が有限数でない場合（`Infinity`・`NaN`）は `'エラー'` を返す
  - _Requirements: 3.2, 5.1, 5.2, 5.3_

- [x] 3. 状態管理ロジックの実装
- [x] 3.1 数字・小数点入力の状態管理
  - 数字ボタン（0〜9）入力時に `displayValue` の末尾へ追加する処理を実装する
  - 小数点入力時に重複チェックを行い、すでに小数点がある場合は無視する
  - 入力値の最大桁数（9桁）チェックを実装し、超過時は入力を無視する
  - `waitingForSecondOperand` フラグが `true` のとき、新しい数字入力で `displayValue` をリセットして入力を開始する
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 2.5_

- [x] 3.2 足し算演算フローの状態管理
  - 「+」ボタン入力時に `firstOperand` を記憶し、`waitingForSecondOperand` を `true` に設定する
  - 「=」ボタン入力時に `firstOperand` と現在の `displayValue` を加算し、結果を表示する
  - 計算結果表示中に「+」をタップしたとき、結果を次の `firstOperand` として連続加算できるようにする
  - 「=」を連続タップしたとき、`lastOperand` を使って直前の加算を繰り返す
  - _Requirements: 3.1, 3.2, 3.3, 3.4_

- [x] 3.3 AC/Cクリア機能の状態管理
  - AC タップ時にすべての状態（`displayValue`・`firstOperand`・`operator`・各フラグ）を初期状態にリセットする
  - C タップ時に `displayValue` のみ `'0'` に戻し、`firstOperand` と演算子は保持する
  - `displayValue` が `'0'` でなくかつ非結果状態のとき、AC/C ボタンラベルを「C」に変えるための判定ロジックを実装する
  - _Requirements: 4.1, 4.2, 4.3_

- [x] 4. (P) UIスタイリングの仕上げとインタラクション表現
- [x] 4.1 (P) 表示エリアのフォントサイズ自動縮小
  - `displayValue` の桁数に応じて表示エリアのフォントサイズを切り替える（7桁以上で縮小・10桁以上でさらに縮小）
  - 表示エリアに `overflow-hidden` を設定して数値がはみ出さないようにする
  - _Requirements: 5.4_

- [x] 4.2 (P) 演算子ハイライトとホバー・レスポンシブ対応
  - 「+」ボタンが選択中（`waitingForSecondOperand === true`）のとき、白背景・オレンジテキストのハイライトクラスを動的に付与する
  - 各ボタンに `hover:brightness-125` を適用して視覚的フィードバックを提供する
  - `max-w-sm mx-auto` などで320px以上のすべての画面幅で適切に表示されることを確認する
  - _Requirements: 1.3, 5.5, 6.1, 6.5_

- [x] 5. ビュー描画とイベントハンドラーの統合
- [x] 5.1 DOM更新ロジックの実装
  - 状態オブジェクトを受け取り、表示エリアの数値・フォントサイズクラスを同期する描画関数を実装する
  - AC/C ボタンのラベル切り替えを描画関数内で処理する
  - 「+」ボタンのハイライト状態を描画関数で制御する
  - 状態が変わるたびに描画関数を呼び出す設計にして、画面が常に最新状態を反映するようにする
  - _Requirements: 4.3, 5.5_

- [x] 5.2 ボタンクリックとキーボード入力イベントの接続
  - 各ボタンのクリックイベントを対応する状態管理関数に接続してアプリを起動する
  - キーボード入力（数字キー・`+`・`Enter`・`Escape`・`Backspace`）を対応する操作にマッピングする
